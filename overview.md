# Project Overview
## Overview
Shortcut Cheatsheet 2.0 is a desktop application 
to help users remember keyboard shortcuts by displaying 
a list of shortcuts for the currently focused application. 
It is designed with a keyboard first UI, where
everything can be done without a mouse and there are ample mnemonics.

## Feature Overview
The application
* Features a "cheatsheet" window displaying a table of 
user defined shortcuts on a per application basis
* Automatically updates the cheatsheet window to match the currently focused 
application
* Has seperate settings window to add, remove, and edit shortcuts.


## Platforms
The app supports the following platforms
* Linux running X11
* Windows 11
